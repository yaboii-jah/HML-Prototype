# Process Flows

## 1. Full Disbursement / Upfront Payment

```text
Site Personnel: Select assigned project and scope
→ Check available project stock
→ Prepare MRF for required materials and quantities
→ Upload supporting PDF and submit MRF
→ Project Manager: Review and approve MRF
→ Archive approved MRF and supporting PDF
→ Procurement: Check stock from other projects
→ Purchase only the remaining quantities
→ Upload supplier quotations
→ Review material matches, quantities, prices, VAT and charges
→ Finalize and archive quotations
→ Compare suppliers and save material awards
→ Generate/archive bid comparison report (optional)
→ Create supplier PO drafts
→ Submit POs to Accounting
→ Accounting: Review costing, VAT/EWT, budget and upfront payment arrangement
→ Approve PO and archive approved PO PDF
→ Procurement: Issue PO to supplier
→ Finance: Coordinate and process supplier payment outside the app
→ Accounting: Upload/archive payment proof
→ Verify full net supplier payment
→ Confirm delivery clearance / release to Logistics
→ Logistics: Schedule and dispatch delivery
→ Site Personnel: Confirm accepted quantities
→ Generate/archive delivery receipt
→ Post accepted quantities to site inventory
→ Upload/archive signed delivery receipt
→ Accounting: Review invoice and delivery documents
→ Site Personnel: Record material usage
```

### Optional Company Warehouse Route

```text
Logistics: Schedule supplier → company warehouse delivery
→ Dispatch shipment
→ Procurement: Confirm warehouse receipt
→ Generate/archive receipt and upload/archive signed receipt
→ Logistics: Schedule onward delivery to the original project
→ Dispatch onward shipment
→ Site Personnel: Receive → Archive receipts → Post site stock
→ Accounting: Review documents
```

### Existing Finance-Managed POs

```text
Accounting-approved and archived upfront PO
→ Accounting: Prepare and submit payment request
→ Finance: Approve payment request
→ Record actual disbursement
→ Repeat requests/disbursements until fully paid
→ Accounting: Release PO to Logistics
→ Delivery → Receiving → Stock posting → Document review
```

## 2. Credit / Terms

```text
Site Personnel: Check project stock → Prepare MRF → Upload PDF → Submit
→ Project Manager: Review and approve → Archive approved MRF and PDF
→ Procurement: Check other-project stock → Source remaining quantities
→ Review/finalize/archive quotations → Compare and save awards
→ Create PO drafts → Submit to Accounting
→ Accounting: Review costing, VAT/EWT and budget
→ Confirm credit / terms and agreed payment due date
→ Approve PO → Archive approved PO PDF
→ Procurement: Issue PO to supplier
→ Delivery and settlement proceed independently
```

### Delivery

```text
Supplier-issued credit PO
→ Accounting: Release to Logistics without waiting for payment
→ Logistics: Schedule → Dispatch
→ Site Personnel: Receive accepted quantities
→ Generate/archive delivery receipt
→ Post site inventory → Upload/archive signed receipt
→ Accounting: Review invoice and delivery documents
→ Site Personnel: Record usage
```

### Settlement

```text
Supplier-issued credit PO
→ Finance: Coordinate payment against the agreed due date
→ Process partial or full payment outside the app
→ Accounting: Upload/archive proof → Verify payment amount
→ Reduce outstanding balance
→ Repeat until fully settled

Unpaid balance after due date → Overdue → Finance follow-up → Payment → Verification

Existing Finance-managed credit PO
→ Accounting: Payment request → Finance: Approval → Actual disbursement
→ Repeat until fully settled
```

## 3. Check Stock / Site Stock Transfer

```text
Site Personnel: Check assigned project's posted inventory
→ Sufficient available stock → Record usage

Insufficient project stock
→ Prepare MRF → Project Manager approval → Archive MRF and supporting PDF
→ Procurement: Open Check site stock
→ Select another project
→ Check matching material descriptions, units and available quantities
→ Select quantities → Review and confirm matches
→ Send source-release request → Reserve selected source stock
→ Source Site Personnel: Review quantities their project can release
→ Approve full or partial quantities
→ Logistics: Schedule one or more transfer trips
→ Dispatch trip → Deduct dispatched quantities from source inventory
→ Destination Site Personnel: Confirm accepted quantities
→ Generate/archive transfer receipt
→ Post accepted quantities to destination inventory
→ Upload/archive signed receipt and supporting evidence
→ Accounting: Review transfer documents
→ Destination Site Personnel: Record usage
```

### Remaining Quantities

```text
No matching stock / source rejection / partial release / receiving shortage
→ Recheck remaining MRF need
→ Source more available stock or purchase the remaining quantities
→ Full disbursement flow or credit / terms flow
```

### Existing Alternative-Stock Reviews

```text
Pending suitability review
→ Destination Site Personnel: Approve or reject suitability and quantity
→ Procurement: Recheck source availability
→ Send source-release request
→ Source approval → Transfer delivery → Receiving → Stock posting → Document review
```

### Returns and Archive Retries

```text
Returned MRF → Site Personnel revision → Resubmit → Project Manager review
Returned PO → Procurement revision → Resubmit → Accounting review
Failed archive → Retry archive → Continue the blocked step
```
