# Separate suitability approval from source-stock reservation

Procurement verifies stock with the same requested description and unit; destination-assigned Site Personnel authorize different or uncertain stock. Suitability reviews hold MRF demand to prevent duplicate purchasing, but hold no source stock and establish no Served coverage. Procurement must recheck availability and explicitly convert an approved review into a source-release request; source Site Personnel retain authority to decide how much their project can spare.

Reserving stock during technical review would prevent the source project from using materials that may ultimately be unsuitable. Leaving MRF demand unrestricted would permit duplicate purchasing while that decision is pending. Separate demand-only holds resolve that trade-off while retaining the transfer and delivery responsibilities established in ADR 0003. Holds require explicit cancellation and do not expire automatically.
